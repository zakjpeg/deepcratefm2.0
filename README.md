# Deepcrate.fm
### Deepcrate.fm is a web-app to discover niche music

## Setup Instructions

1. Create a .env file in root folder & add two environment variables:
- DISCOGS_TOKEN: Discogs API token (get one by generating a Personal Access Token in Discogs developer settings)
- DISCOGS_USER_AGENT: A string representing your user agent

2. Install packages using 'yarn add' or 'npm install'

3. Run using 'yarn dev' or 'npm run dev'
